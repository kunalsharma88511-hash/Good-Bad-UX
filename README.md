# User Experience (UX) refers to how a user feels while interacting with a website or mobile application.
## A Good UX makes an application easy to use, simple to understand, and convenient for users.
## A Bad UX creates confusion, takes extra time, and makes it difficult for users to complete their tasks.
  
## Objective
## The objective of this assignment is to identify and analyse 3 good UX and 3 bad UX examples from popular mobile applications.

# Applications Selected

### Good UX Examples
1. Netflix
2. Paytm
3. Amazon

### Bad UX Examples
1. PhonePe
2. Meesho
3. SonyLIV
